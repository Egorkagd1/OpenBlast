## ✨ Почему OpenBlast?

Оригинальная игра потрясающе залипательна, но в официальных маркетах превратилась в машину по показу 30-секундных непропускаемых реклам казино и сбору телеметрии.

**OpenBlast решает эту проблему раз и навсегда:**
- 🚫 **0% рекламы**: Никаких баннеров, видеороликов, навязчивых предложений.
- 🔒 **100% Приватность**: 0 аналитики, 0 трекеров, работает без интернета.
- ⚡ **Легковесность**: Никаких 60-мегабайтных Unity-рантаймов. Чистый нативный Android (APK ~3–5 МБ).
- 🎯 **Тактильность (Juiciness)**: Haptic Feedback при установке и сгорании линий, всплывающие комбо, партиклы взрывов.
- 🔊 **Процедурный синтез звука**: Звуки генерируются на лету через PCM-синтез (никаких чужих тяжелых аудиофайлов).
- 👆 **Finger Offset UX**: При перетаскивании фигура парит чуть выше пальца, чтобы ваш палец не закрывал обзор сетки.

## 🎮 Правила игры

1. Перетаскивайте фигуры с нижней панели на поле **8x8**.
2. Заполняйте строки и столбцы целиком, чтобы они сгорали (**Blast**).
3. **Комбо**: сжигайте линии несколько ходов подряд для умножения очков (`Combo x2`, `x3`, `x4`...).
4. Если ни одна из 3 доступных фигур не помещается на поле — игра завершается.

## 🛠 Стек технологий

- **Язык**: Kotlin 2.3+
- **UI Toolkit**: Jetpack Compose (BOM 2026.03+ / Material 3)
- **Графика**: Compose Canvas с аппаратным ускорением (120 FPS)
- **Архитектура**: Clean MVI / StateFlow + Android ViewModel
- **Звук**: Процедурный PCM аудио-синтезатор (AudioTrack)
- **Вибрация**: Android VibratorManager / VibrationEffect

## 📦 Сборка проекта

### Требования:
- JDK 17+
- Android SDK 36 (Android 7.0+ / MinSdk 24)

### Команды:
```bash
# Клонировать репозиторий
git clone https://github.com/your-username/openblast.git
cd openblast

# Сборка Debug APK
./gradlew assembleDebug

# Готовый APK появится в:
# app/build/outputs/apk/debug/app-debug.apk
```
